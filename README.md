# warframe-wiki-scraper

Extract Warframe wiki modules into readable JSON files.

## Setup

1. Create and activate virtual environment:
```bash
python3 -m venv env
source env/bin/activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the script:
```bash
python3 main.py
```

4. Outputs:
JSON files will be saved on `data/` folder
